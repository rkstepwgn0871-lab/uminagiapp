# 🌊 海凪（うみなぎ）業務アプリ

介護現場向けのデータ入力・集計を爆速化するPWA（Progressive Web App）です。  
Google Apps Script (GAS) とスプレッドシートをデータベースとして活用し、フロントエンドをGitHub Pagesで分離配信することで、**0.1秒の高速起動**と**専用アプリのような操作感**を実現しています。

---

## 📱 アプリ公開URL
👉 **https://rkstepwgn0871-lab.github.io/uminagiapp/**

### iPad・iPhoneでのホーム画面追加手順
1. iPadのSafariで上記URLを開く
2. 画面右上の **共有ボタン（四角から上向き矢印 ⎋）** をタップ
3. メニューから **「ホーム画面に追加」** を選択
4. 右上の **「追加」** をタップ  
👉 ホーム画面のアイコンから、URLバーのない全画面ネイティブアプリとして起動できます。

### 1. 画面・ボタン・使い勝手を変えたいとき ➔ **GitHub（MacのFinder）**
iPadに表示される**見た目や操作性**に関するものはすべて、MacのFinderにある `index.html` を直します。

| こんな変更のとき | 編集する場所 |
| :--- | :--- |
| ボタンの大きさ、配置、色を変えたい | `index.html` |
| 音声入力で聞き取る言葉（「欠席」「入院」など）を増やしたい | `index.html` |
| テンキーの配置や押しやすさを調整したい | `index.html` |
| 利用者のカードレイアウトを変更したい | `index.html` |

#### 🌟 更新手順（超ラク！）
1. MacのFinderで `書類/GitHub/uminagiapp/index.html` を編集して保存
2. **GitHub Desktop** を開いて、左下の青いボタン **「Commit to main」➔「Push origin」** をクリック  
👉 **これだけで1〜2分後にiPadのアプリに自動反映されます！（GASの操作は一切不要）**

---

### 2. シートの列や保存ルールを変えたいとき ➔ **GAS（Apps Script）**
スプレッドシートの**列や計算、裏側のデータ処理**を変えるときだけ、GASを触ります。

| こんな変更のとき | 編集する場所 |
| :--- | :--- |
| スプレッドシートの列やシート名（例: 来年「2027」にするなど）を変えた | Apps Script (`Code..gs`) |
| 体重と一緒にBMIなどを自動計算してシートに入れたい | Apps Script (`Code..gs`) |
| 名簿同期のルールを変えたい | Apps Script (`Code..gs`) |

#### ⚠️ GAS更新時の必須操作
コード変更後、必ず **「デプロイ」➔「デプロイを管理」➔ 鉛筆マーク ✏️ ➔ バージョンを「新バージョン」** にして「デプロイ」を押してください。
